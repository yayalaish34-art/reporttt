# מקרי ולידציה (Golden Dataset)

כל תיקייה היא מקרה אחד. `backend/tests/test_golden.py` מריץ את כולם בכל שינוי במנוע.

| קובץ | חובה | תוכן |
|---|---|---|
| `geometry.json` | כן | רשימת המקורות, באותו פורמט שהמנוע מקבל |
| `inputs.json` | כן | נקודות החישוב ושיטת השילוב |
| `expected_results.json` | כן | הערכים הצפויים, הסבולת ו-`provenance` |
| `reference.pdf` | לא | דוח או פלט של תוכנת חיזוי |
| `measurement.csv` | לא | עמודות `x,y,z,measured_mg,instrument,date` |

`provenance` מציין מאיפה הערך הצפוי:

| ערך | משמעות |
|---|---|
| `ANALYTIC` | נגזר מפתרון סגור, ללא שימוש במנוע |
| `EXTERNAL_SOFTWARE` | פלט של תוכנת חיזוי אחרת |
| `FIELD_MEASUREMENT` | מדידה בשטח |

## מצב נוכחי

**כל המקרים כאן הם `ANALYTIC`.** הם מוכיחים שהמנוע פותר נכון את המשוואה, ולא שהמודל תואם מציאות. כדי להשלים ולידציה אמיתית צריך להוסיף כאן פרויקטים של גלית עם מדידות שטח וגם השוואה לתוכנת החיזוי הקיימת.

אם `expected_results.json` של מקרה ממדידה לא עובר אחרי שינוי, בודקים למה. לא מעדכנים את הערך הצפוי כדי שהבדיקה תעבור.
